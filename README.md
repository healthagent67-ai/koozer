# Koozer Painting

Static website for Koozer Painting (Charleston, SC).

- `index.html` is the finished home page.
- `about-us`, `services`, `areas-served`, `free-estimate`, `contact-us` and the four service pages
  (`interior-painting`, `exterior-painting`, `commercial-painting`, `specialty-services`) are blank
  placeholders that share the site header and footer. Content to be added.

No build step. Open `index.html`, or serve the folder with any static server.
